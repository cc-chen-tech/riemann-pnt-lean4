# Monotone Variable-Boundary Signed Omega Design

## Goal

Upgrade the end-to-end transfer from a one-sign alternative to a conditional
simultaneous `Omega+` and `Omega-` theorem.

## Method

Use stack108's same automatic residual for both signed moving-package
witnesses. The generic natural-point signed transfer preserves each witness
with coefficient loss `loss`. Embed both witnesses into the real-variable
interface, then use the exact identity

```text
x * x^(beta(x)-1) = x^beta(x)
```

to recover the unnormalized Chebyshev error. Stack102 removes the
absorption-or-gap assumption from monotonicity.

## Claim boundary

Independent positive and negative moving-package witnesses remain explicit
inputs owned by the Sharp/anti-cancellation work. The theorem is conditional
`Omega±`; it does not prove those witnesses or RH.
