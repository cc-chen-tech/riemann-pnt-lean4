# Automatic reciprocal sign alternative design

Starting from a nonempty finite target-line seed, the existing automatic
energy-boundary budget chooses a package height `T` and smoothing length `L`
such that:

- the seed lies in the actual equal-real-part package;
- the package energy is positive;
- its outside Carlson boundary mass is below half the sampled coefficient.

Stack161 then transfers the package mean-square sign alternative to the true
relative PNT error.  The combined theorem requires only `sigma < beta`, rather
than `(1+sigma)/2 < beta`.

The global outside-cluster real-part cap and strict real-ordinate exclusion
remain explicit.  The result supplies one persistent sign, not simultaneous
positive and negative witnesses, and does not imply RH.
