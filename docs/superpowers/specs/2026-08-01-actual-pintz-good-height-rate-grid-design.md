# Actual Pintz Good-Height Rate Grid

## Goal

Replace the abstract candidates `pintzCarlsonHeight k x` in a finite rate grid
by actual analytic good heights selected in the unit interval immediately below
that ceiling.

## Candidate family

A rate grid contains a finite nonempty set of positive rates, a least base
rate, and one `UniformNaturalPointGoodHeightSelection`. For rate `k`, define

```text
H_k(x) = selection.height (pintzCarlsonHeight k x - 1)
```

when the ceiling is at least nine, and use a fixed positive fallback at small
scales. Every eventual candidate is therefore a good height in

```text
[pintzCarlsonHeight k x - 1, pintzCarlsonHeight k x].
```

All rates share the selector's explicit-formula constant.

## Dynamic grid

The regularized lower envelope is generated by the least rate. Monotonicity of
`exp(k * sqrt(log-scale))` in `k` places it below every candidate, and the
positive base rate makes it tend to infinity.

The finite-grid optimizer therefore:

- tends to infinity;
- is exactly one candidate `H_k(x)` at each scale;
- minimizes the supplied pointwise cost over all certified rates;
- is eventually an analytic good height in the corresponding Pintz interval;
- carries a natural-point truncated explicit-formula certificate at exactly
  the optimized height.

## Boundary

This stack constructs the actual rate grid but does not yet prove decay of a
switching full PNT budget or a continuous-rate discretization loss. It does not
prove unconditional Omega or RH.
