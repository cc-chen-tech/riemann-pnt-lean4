# Running-boundary reciprocal sign-alternative design

## Objective

Use the actual visible-zero running maximum instead of an attained global
right edge, while reducing the oscillatory input from two signed witnesses to
one unsigned moving-package witness.

## Transfer chain

The natural running boundary is built from the maximum real part of the
positive nontrivial zeros visible at each canonical selected height.  It is
sampled-monotone, lies above a fixed anchor `beta0`, and automatically bounds
every currently visible Carlson-indexed positive zero.

The reciprocal residual theorem applies under

```text
sigma - beta0 + epsilon < 0,
```

with no polynomial-height exponent loss.  It simultaneously supplies the
moving-scale PNT upper bound.  A single unsigned moving-package witness is
split into a positive-or-negative alternative and transferred through the
same residual to the exact unnormalized scale `x^(beta x)`.

## Claim boundary

The running boundary and analytic residual are automatic actual-zeta objects.
The unsigned moving-package witness remains an explicit input.  The theorem
does not prove that witness, simultaneous signed Omega, a global maximum, or
RH.
