# Attained right-edge real-closed seed design

At an attained global right edge, enlarge the conjugate-pair seed by every
real-ordinate nontrivial zero whose real part equals the attained maximum.
The added set is finite because it is filtered from the existing finite
real-ordinate zero set.

Every member remains on the target line.  If an actual equal-real-part package
contains this seed, any real-ordinate zero outside that package has real part
at most the global maximum and cannot attain equality.  It therefore lies
strictly to the left.

This construction prepares removal of the explicit global real-ordinate
strictness hypothesis from the reciprocal Omega facade.  It does not assert
that a global maximum exists or that both oscillation signs occur.
