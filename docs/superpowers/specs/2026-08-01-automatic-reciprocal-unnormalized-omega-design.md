# Automatic reciprocal unnormalized Omega design

Stack162 returns a positive coefficient and a natural-point sign alternative
for the relative error `(psi0(x)-x)/x` at scale `x^(beta-1)`.  The standard
real-point conversion yields a sign alternative for `psi0(x)-x` at scale
`x^beta` with the same positive coefficient.

The conclusion is `Omega_+` or `Omega_-`; it is not simultaneous
`Omega_+` and `Omega_-`.  The outside-cluster real-part cap and strict
real-ordinate exclusion remain explicit, so the theorem is not RH.
