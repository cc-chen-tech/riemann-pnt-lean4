# Attained right-edge real-closed reciprocal Omega design

## Scope

Remove the global hypothesis that every real-ordinate nontrivial zeta zero is
strictly left of an attained maximal real part.  Keep explicit maximum
attainment, the reciprocal Carlson threshold `sigma < beta`, and the exact
unnormalized `x^beta` scale.

## Theorem chain

1. Replace global real-zero strictness in the fixed-package residual transfer
   by strictness only for `realOrdinateNontrivialZerosOutsideClusterFinset`.
2. Let the existing energy-boundary budget select an equal-real-part package
   containing a finite target-line seed.
3. Require the seed interface to supply the package-local real gap for every
   selected package containing that seed.
4. Instantiate this interface with `attainedGlobalRightEdgeRealClosedSeed`,
   which contains all real-ordinate zeros on the attained maximal line.
5. Convert the natural-point relative sign witness to an unnormalized real
   witness at coefficient times `x^beta`.

## Claim boundary

The result is conditional on explicit attainment of a global maximal real
part and returns `Omega_+` or `Omega_-`.  It does not prove both signs, does not
prove attainment, and does not imply RH.
