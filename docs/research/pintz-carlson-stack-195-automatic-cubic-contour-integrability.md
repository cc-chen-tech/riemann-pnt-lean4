# Stack 195: automatic cubic contour integrability

## Result

The existing rectangle boundary hypothesis now automatically proves that the
actual third-order explicit-formula integrand is interval-integrable on the
bottom, top, and left contour edges.

The proof uses the strict-interior boundary condition to exclude the zeta pole
and every zeta zero from each edge.  Positivity of the left boundary excludes
the Perron origin.  The cubic integrand is therefore analytic at every path
point, hence continuous and integrable on each compact interval.

Stack 194's pathwise second-difference factorization is then instantiated on
all three actual contour edges with no external integrability premise.

## Mathematical role

The de-smoothed contour is now an actual first-order explicit-formula contour
with the same multiplier as the finite zero sum.  The remaining contour gap is
quantitative norm control, not existence or legitimacy of the integrals.

## Claim boundary

No upper bound for the three de-smoothed contour integrals is proved here.
This does not establish an unconditional oscillation theorem or RH.
