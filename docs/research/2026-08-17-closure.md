## Key insight (the one I missed in earlier rounds)

The key insight is that the cluster main term, for FINITE S, is a continuous
function of log m (it's a finite sum of cosines times an amplitude envelope).
Therefore:
- The max of |cluster_main/amp| over all m is positive (numerical: 0.531 for N=14).
- For c < max, the set {m : |cluster_main(m)|/amp(m) > c} is non-empty and open.
- For any M, the interval (M, M+1) intersects this set, so there are
  arbitrarily large m with the desired property.
- Hence the far-natural-point property holds.

This is the "continuous function achieves max → far-natural-point" argument.
The proof skeleton captures this structure.
