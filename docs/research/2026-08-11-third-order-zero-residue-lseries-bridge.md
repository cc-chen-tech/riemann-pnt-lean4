# Explicit zero residue in the second-smoothed formula

This slice completes the local-to-global coefficient-identification chain for
the genuine third-order zeta kernel.

The theorem now places the following objects in one statement:

- the actual `secondSmoothedChebyshevPsi` value;
- the finite analytic-multiplicity-weighted residue sum;
- the genuine negative-left-edge third-order contour remainder;
- the explicit Perron truncation error;
- the exact zero-pole coefficient
  `iteratedDeriv 2 (thirdOrderZeroCore x) 0 / 2`.

Thus the zero contribution is no longer represented by an unconstrained
abstract function value in the PNT-level smoothed explicit formula.

This theorem does not by itself prove an Omega result, RH, a zero-free region,
or decay of the normalized complementary zero tail. Those remain separate
analytic transfer problems.
