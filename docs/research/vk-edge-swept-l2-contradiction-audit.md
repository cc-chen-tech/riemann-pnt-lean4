# Swept local L2 contradiction audit

## Verified conditional conclusion

Fix `epsilon > 0`. If the Riemann zeta function has a zero
`rho = beta + i gamma` with

```text
1 / 2 < sigma < beta < 1 and gamma > 0,
```

then the swept Gaussian argument supplies a missing odd harmonic `k` and an
explicit constant

```text
c(rho, epsilon, k) > 0
```

such that, for every sufficiently large `Y`,

```text
c(rho, epsilon, k) * log Y
  <
integral over [log Y, (1 + epsilon) log Y]
  of normalizedPsiError(rho, y)^2.
```

The interval has length `epsilon * log Y`. Thus the lower bound is linear in
the window length, rather than merely of square-root size. The Lean endpoint is
`exists_eventually_ordinarySecondMoment_in_epsilonLogWindow_gt_linear`.

This is still conditional on the existence of an off-critical-line zero. It
does not assert such a zero exists.

## What this can imply next

A fourth-moment bound of matching scale,

```text
integral |normalizedPsiError(rho, y)|^4 dy = O(log Y),
```

together with the proved second-moment lower bound, would yield a
fixed-proportion large-value set through a Paley-Zygmund or equivalent
Cauchy-Schwarz argument. The present branch does not prove that fourth-moment
bound, so it does not yet prove a fixed-proportion positive-measure theorem.

## Exact contradiction threshold

For every `beta > 1 / 2`, an independent unconditional estimate

```text
integral over [log Y, (1 + epsilon) log Y]
  of normalizedPsiError(rho, y)^2
    = o(log Y)
```

would contradict the theorem above and exclude zeta zeros with real part
`beta`. Excluding all zeros with real part greater than `1 / 2`, followed by
the functional-equation symmetry, would imply the Riemann Hypothesis.

No such upper bound is proved here. Proving it uniformly for every
`beta > 1 / 2` is already an RH-strength task.

## Why current unconditional estimates do not contradict it

Known unconditional prime-number-theorem error bounds are much larger than the
square-root scale after normalization by `exp(beta * y)`. They therefore do
not give an `o(log Y)` upper bound for this second moment.

Carlson zero density bounds the number of zeta zeros in a right half-plane.
The present theorem bounds the energy of the prime-counting error generated by
one hypothetical zero. It neither constructs additional distinct zeta zeros
nor injects large-value windows into a zero-counting set. Consequently there is
currently no Carlson contradiction.

## Claim boundary

This branch proves:

- an explicit positive local second-moment constant;
- a lower bound linear in `log Y` in every sufficiently late epsilon window;
- the analytic interface needed for a future quantitative measure argument.

It does not prove:

- a fixed-proportion large-value set;
- an unconditional local second-moment upper bound;
- a zero-density contradiction;
- exclusion of off-critical-line zeros;
- the Riemann Hypothesis.
