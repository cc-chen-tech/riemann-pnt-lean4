# Stack 173: near-optimal prescribed height and moving-window transfer

## Result

For a prescribed outer height exponent `0 < alpha < 1` and any
`0 < delta < alpha`, the automatic anchor lies between

```text
prescribedHeightAnchorFloor sigma alpha
```

and that floor plus `delta`.  The selected explicit-formula height is
cofinal and eventually bounded by `x^alpha`.

Under one strict far-window square-energy lower bound for the normalized
moving zeta package, the same theorem also gives:

- the variable-scale relative PNT upper bound;
- a positive surviving coefficient `c - loss`;
- `Omega_+` or `Omega_-` for the unnormalized Chebyshev error at the exact
  moving exponent.

## Improvement over the previous interface

The previous near-optimal prescribed-height theorem required separate
positive and negative moving-package witnesses.  This stack needs only one
unsigned local square-energy input and concludes a mathematically correct
one-sign alternative.

## Claim boundary

The local square-energy input remains conditional.  The theorem does not
prove both signs, a global rightmost zero, zero reproduction, or RH.  It does
put the near-optimal height choice, Carlson/Pintz upper transfer, and the
explicit-formula lower transfer in one audited theorem statement.
