# Explicit Formula Route Dependency Map

This note maps the current
`PrimeNumberTheorem.explicit_formula_von_mangoldt` target to the analytic
infrastructure it would need before it can be more than a `sorry` placeholder.
It is a route map, not a proof plan claiming the current Lean project already
has these ingredients.

## Current Lean Target

`PrimeNumberTheorem.lean` states the von Mangoldt explicit formula in the form

```lean
theorem explicit_formula_von_mangoldt (x : ℝ) (hx : x ≥ 2) :
    chebyshevPsi x = x
    - ∑' ρ : {s : ℂ // RiemannHypothesis.IsNontrivialZero s},
        (x : ℂ) ^ (ρ : ℂ) / (ρ : ℂ)
    - (deriv riemannZeta 0) / riemannZeta 0
    - (1 / 2) * Real.log (1 - x^(-2 : ℝ)) := by
  sorry
```

The statement compresses several hard analytic steps into one theorem:
recovering `psi(x)` from the logarithmic derivative of zeta, moving a contour,
collecting residues, and making sense of the infinite sum over nontrivial
zeros.

## Dependency Chain

| Layer | What it must provide | Current blocker |
|---|---|---|
| Von Mangoldt Dirichlet series | A Lean theorem for `-ζ'(s)/ζ(s) = ∑ Λ(n)n^(-s)` in a right half-plane | Local `vonMangoldt`/`chebyshevPsi` definitions need a theorem-level bridge to Mathlib analytic-number-theory APIs. |
| Perron formula | A version converting a Dirichlet series into a weighted step sum for `psi(x)` | Needs reusable Perron machinery over vertical line integrals; this is not present locally. |
| Contour integration | Rectangular contour shift from `Re s = c > 1` past poles and zeros | Needs complex line-integral estimates, zeta growth bounds, and a formal way to control horizontal/left-edge integrals. |
| Residue theorem | Extraction of residues from `-ζ'/ζ(s) * x^s/s` | Needs residue theorem instances in exactly the form required for meromorphic logarithmic derivatives. |
| Pole term at `s = 1` | The residue at the zeta pole contributes the main term `x` | Local `riemannZeta_residue_one` and `riemannZeta_pole_simple` are useful, but the log-derivative residue calculation still needs to be formalized. |
| Nontrivial zero terms | Each nontrivial zero contributes `-x^ρ/ρ` with multiplicity | Requires a precise zero multiset or subtype, multiplicity handling, and compatibility with the stated `IsNontrivialZero` subtype sum. |
| Trivial zero terms | Trivial zeros contribute the logarithmic correction term | Needs zeta trivial-zero classification and summation of the resulting elementary series. |
| Constant term | The `-(ζ'(0)/ζ(0))` term must be separated from the shifted contour residues | Needs zeta value/nonzero facts at `0` plus derivative/log-derivative residue bookkeeping. |
| Zero-sum convergence | The infinite zero sum must be interpreted and shown to converge in the needed sense | Needs zero-counting estimates, symmetric truncation conventions, or a theorem matching the exact `tsum` formulation. |

## Mathlib-Level Blockers

- Perron's formula for Dirichlet series with explicit truncation/error terms.
- A contour-shift framework for meromorphic functions with controlled boundary
  integrals.
- Residue theorem automation for logarithmic derivatives such as `ζ'/ζ`.
- Zeta zero-counting or zero-density infrastructure strong enough to justify
  zero-sum convergence.
- A canonical bridge between Mathlib's Chebyshev/von Mangoldt definitions and
  this repository's local `chebyshevPsi`.
- Multiplicity-aware zeta zero indexing compatible with infinite sums over
  nontrivial zeros.
- Formal trivial-zero contribution calculation producing
  `-(1 / 2) * log(1 - x^(-2))`.

## Computational Companion

The companion script `experiments/rh/explicit_formula.py` deliberately models
only the finite paired nontrivial-zero contribution
`-2 * Re(x^ρ / ρ)` for `ρ = 1/2 + iγ`, using the same early zero ordinates
fixture as the Li-coefficient experiment. It compares that toy contribution to
the raw `psi(x) - x` values generated by `experiments.pnt.pnt_experiments`.

This script is not evidence for the full theorem. It omits the pole,
trivial-zero, constant, convergence, multiplicity, and contour-error terms that
the Lean theorem must account for.

## Next Formalization Targets

1. State a local Perron-formula interface with all hypotheses explicit, even if
   it initially remains unproved.
2. Split `explicit_formula_von_mangoldt` into named lemmas for the pole term,
   nontrivial-zero residues, trivial-zero residues, and convergence/error
   control.
3. Replace the unstructured `tsum` over nontrivial-zero subtypes with a
   multiplicity-aware formulation or document why the current subtype sum is
   sufficient.
4. Prove the local `chebyshevPsi` bridge before attempting contour machinery, so
   later analytic statements target a single ψ definition.
