# Natural PNT lower transfer from a concrete zeta zero

Given a nontrivial zeta zero `rho` captured below height `T`, the
equal-real-part package at `(T, Re rho)` is nonempty. The positive-energy
theorem therefore supplies a window `L > 0` with positive package energy.

For a uniform natural good-height selector and any `0 < q < 1`, the module
then derives the full relative-Chebyshev far witness at scale

```text
q * sqrt(E(T, Re rho, L)) * x^(Re rho - 1) / 2.
```

The Carlson outside-cluster finite-strip certificate remains an explicit
hypothesis. Thus this theorem is a concrete zero-to-PNT transfer interface,
not an unconditional Omega theorem.
