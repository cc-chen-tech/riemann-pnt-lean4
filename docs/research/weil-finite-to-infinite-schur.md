# Weil 有限到无限 Schur 闭合诊断

## 这次增加了什么

现有证书已经能够严格证明一个有限 Weil 矩阵具有正余量。新框架不再把
“有限矩阵为正”误写成无限维结论，而是把还缺少的数学条件单独列出来并做
精确判定。

```text
低频有限块：已有 Lean/LDL 证书
        |
        +--- 高频余块：需要新的解析下界
        |
        +--- 低频/高频耦合：需要新的解析上界
        |
        v
Schur 条件满足，才允许推出整体非负
```

## 四个数分别是什么

- `epsilon`：低频有限块的严格正余量。它由现有区间证书精确计算：

  `epsilon = center_lower_bound - perturbation_row_bound`。

- `delta`：归一化有限近似与完整对象之间的算子范数误差上界。

- `gamma`：无限维高频余块的统一下界。

- `beta`：低频块和高频块之间耦合的范数上界。

有两条独立的充分路线。

归一化尾界路线要求：

`delta <= epsilon`。

Schur 路线要求：

`beta^2 <= epsilon * gamma`。

Lean 模块
`WeilExtremalKernels/FiniteToInfiniteSchur.lean`
证明了这两条传递逻辑。诊断脚本只用精确有理数检查不等式。

## 当前 N=16/32 会得到什么结果

当前 artifacts 能提供 `epsilon`，但没有提供经过证明的 `delta`，也没有提供
经过证明的 `gamma` 和 `beta`。因此诊断结果应为：

`MISSING_ANALYTIC_BOUNDS`

它的意思不是有限证书失败，而是：

> 低频部分已证明，但尚无权对没有进入有限矩阵的全部方向作结论。

脚本不会把缺失的界当作零，也不会用浮点拟合替代严格上界。

## 三种结果

- `CLOSES`：至少一条充分不等式成立。
- `BOUND_FAILS`：给出的严格界完整，但还不足以压过有限余量。
- `MISSING_ANALYTIC_BOUNDS`：缺少高频或尾项的解析证明数据。

即使输出 `CLOSES`，它也只说明“所提供的假设足以推出整体非负”。要形成真正
的 Weil 定理，还必须在数学上证明这些 bounds 确实属于目标 Weil 二次型。

## 下一步真正的数学任务

第一步不是继续增大 N，而是选择一个正参考形式 `A`，把目标形式写为：

`Q = A^(1/2) (I + T) A^(1/2)`。

然后在同一个归一化下研究：

1. 有限块 `I + P_N T P_N` 的严格余量；
2. 系数尾部 `T - P_N T P_N` 的严格范数上界；
3. 比值 `delta_N / epsilon_N` 是否随 N 下降。

如果这个比值稳定下降，归一化尾界路线可能闭合。如果它增长，就应更换参考
形式或基函数，而不是继续堆更大的有限矩阵。

Schur 路线则需要把目标空间分成低频和高频，分别证明：

1. 高频部分至少有 `gamma_N` 的正性；
2. 低频和高频的耦合不超过 `beta_N`；
3. `beta_N^2 <= epsilon_N * gamma_N`。

## 仍然分开的两个极限

完成固定参数下的 `N -> infinity` 仍然不等于 RH。还需要处理支持范围或
cutoff 参数 `c -> infinity`，从而覆盖 Weil 判据允许的完整测试函数类。

因此当前项目边界是：

```text
有限证书 epsilon：已具备
N 方向解析尾界：待证明
c 方向覆盖定理：待证明
完整 Weil 判据或 RH：未得到
```
