# Stack 172: moving-window L2 handoff

## Scope

This stack connects a repeatable local square-energy statement for the
normalized natural running-boundary zero package to the reciprocal unified
PNT transfer from Stack 171.

It does not modify Sharp oscillation, VK-edge, or complementary-bound modules.

## Analytic input

For every natural cutoff `M`, assume there is a finite set `G` beyond `M`
such that

```text
card(G) * c^2 < sum_{m in G} normalizedMain(m)^2.
```

Here `normalizedMain(m)` is the actual finite zeta-package main term divided
by the exact moving target amplitude associated with the natural running
visible-zero boundary.

## Theorem chain

1. Strict finite-window square energy forces some `m in G` with
   `c <= |normalizedMain(m)|`.
2. Eventual positivity of the moving target amplitude removes the
   normalization and yields the exact Stack 171 unsigned witness
   `c * variableBoundaryTargetAmplitude beta m <= |main(m)|`.
3. Stack 171 supplies both the eventual variable-scale PNT upper bound and an
   `Omega_+` or `Omega_-` alternative at coefficient `c - loss`.

## Claim boundary

rightmost zero, zero reproduction, or RH.  The remaining analytic task is to
derive the strict moving-window square-energy inequality from a repeatable
