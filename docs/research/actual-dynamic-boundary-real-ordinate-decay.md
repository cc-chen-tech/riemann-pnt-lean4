# Dynamic-boundary real-ordinate decay

The positive-height Carlson tail does not include zeros with imaginary part
zero. The repository deliberately keeps this finite residual instead of
assuming that it is empty.

Let

\[
Z_{\mathbb R}=\{\rho:\zeta(\rho)=0,\ 0<\Re\rho<1,\ \Im\rho=0\}.
\]

For each fixed member of this finite set:

- If `Re rho < beta`, its normalized kernel tends to zero.
- If `Re rho = beta`, every eventually nonnegative height includes it in the
  dynamic equal-real-part package, so its complementary contribution is
  eventually exactly zero.

Thus the non-strict right-edge condition

\[
\Re\rho\le\beta\quad(\rho\in Z_{\mathbb R})
\]

is enough to prove

\[
\frac{\|R_{\mathbb R}(m)\|}{m^{\beta-1}}\longrightarrow0.
\]

No zero-free assertion on the real segment and no uniform strict real-part
gap are introduced.
