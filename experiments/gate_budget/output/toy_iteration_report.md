## Interpretation

- grid/poisson (average density O(log T)): max gap ~ 1/log T,
  branching stays bounded for fixed delta, kappa = 0; fixed-depth
  hgap needs q(T) ~ T^e, which these models cannot supply,
  matching the Lean no-go theorem for single-window certificates.
- cluster (super-logarithmic local density): the reachable set and
  branching grow with the cluster density; this shows what the
  coherent energy mechanism would need to deliver (e_M > 0, i.e.
  beta > 10/13 in the pointwise model).
- a half-isolated seed whose window contains no higher imaginary
  part terminates the iteration at once (layers = 1).
